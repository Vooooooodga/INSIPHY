# Scientific validation priorities

The v18 implementation defines local structural characters and elementary
phylogenetic changes. Its next scientific priorities are independent end-to-end
accuracy benchmarks, annotation/assembly-error experiments, rate-model calibration
and curated biological comparisons. These require evidence, not additional
mechanistic event labels.

Complex rearrangements, multicopy histories, complete ancestral transcripts,
expression/activity inference and selection are outside the formal current model.
Any future extension requires a state space, observation model, event definition
and validation appropriate to that biological target.
