# Quick start

Install the package, MAFFT and minimap2 as described in [installation](installation.md).
Run the complete raw-input commands in the [README](../README.md). Start with
`intraphy example`, validate with `intraphy check`, prepare with `build-case`,
reconstruct with `run`, and inspect with `visualize`.

All paths and output semantics are described in [CLI use](cli.md), [inputs](input_format.md)
and [outputs](outputs.md). An unavailable CTMC fit is not evidence that no event
occurred. Read [counting rules](event_counting.md) before totaling branch rows.
