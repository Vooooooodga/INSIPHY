# Bap170 Real Positive Case

This case prepares the Farlow et al. 2010 Drosophila pseudoobscura intron-gain
example. The published event is a 218 bp gain in `Bap170`, of which 206 bp are
spliced out.

The D. pseudoobscura focal genome is prepared first. The current RefSeq focal
gene ID and comparator rows remain pending until the GFF/protein files have
been downloaded and matched.
