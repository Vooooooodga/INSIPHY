# BCKDK Real Positive Case

This case prepares a mammalian intron-loss example centered on rat `Bckdk`.
The comparative intron-loss benchmark source is Coulombe-Huntington and
Majewski 2007. Muller and Danner 2004 provide BCKDK biochemical and transcript
context for interpreting the gene.

The current files are preparation records. The chimpanzee RefSeq gene ID and
the exact modern intron coordinate should be confirmed from downloaded
annotations before scoring.
