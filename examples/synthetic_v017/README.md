# Synthetic 0.17 prepared-input example

This is **not real organism data and not an alignment-accuracy benchmark**.
A/B/C/D are fictitious species. C is on the negative strand; B has split E3 pieces;
D has an unresolved E3 correspondence. C and D have explicit E4 absences;
E4 therefore has two equally parsimonious gain/loss histories on the supplied tree.
A shorter annotated transcript, antisense exon, ncRNA and repeat are gray context.
Q has DNA coordinates without transcript membership. Its low-callability character
remains in the full catalogue and background, even when excluded from a high-coverage fit.
The provided homology blocks and observations test downstream contracts, not inferred truth.

The builder runs fixed-tree parsimony and the actual grouped renderer.
Original coordinates and all supplied features must be identical in every group.
